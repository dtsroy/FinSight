# FinSight 📊

> **你的下一代个人财富洞察中枢**
> 
> *Every Great Product Starts with Context. 真正的理财投顾，从理解你的每一笔资产开始。*

FinSight 是一款基于 Electron 构建的桌面级财富管理应用。我们将机构级的金融分析模型（底层穿透、压力测试）与前沿的大语言模型深度融合，旨在成为**普通人的首个智能理财教练与决策陪伴中枢**。

我们的设计哲学代号为 **Pawn（兵）**。
在金融的棋局中，散户往往是最容易被牺牲的 Pawn。但通过无数个精准执行的 API 与 Agent “小兵”的协同，我们将原本只属于高净值人群的机构级视野，赋能给每一个普通的 Pawn。当无数个 Pawn 获得全盘的 Context，便能化被动为主动，直击棋局的核心。

## 🎯 赛道切入点：Context 与真实痛点

### 1. 目标人群
**具备一定资产积累，但缺乏体系化认知的理财新手与新中产。**
他们广泛使用各类理财工具，但资产极度分散（银行、第三方平台、券商等），无法形成全局视角的资产管理。

### 2. 真实存在的痛点（Why this problem?）
* **“糊涂账”现象**：各大平台的资产犹如孤岛。用户每天重复打开多个 App 汇总资产，却依然无法看清真实的跨市场配置比例。
* **黑盒化投资**：持有多只基金，却不知底层重仓了相同的股票。一遇行业动荡，全盘皆崩。
* **情绪化交易**：市场波动时极度焦虑，缺乏客观、冷静的决策陪伴。
* **Why Us？**：我们自己就是痛点的亲历者。每天手动整合资产的折腾，构成了我们最宝贵的 Context。我们不是在空想一个软件，而是在解决切肤之痛。

## 🤖 产品哲学：重塑投顾交互

我们坚信：**真正的智能，不是把传统问卷包装成聊天框，而是改变交互范式，将专业的“投顾服务”平民化。**

### 1. 决策生成引擎
* **全景 Context 注入**：摒弃静态问卷。基于用户的全局资产账本（含穿透后的底层持仓）作为核心 Context，确保建议的精准度。
* **认知框架重塑**：不提供直接的买卖指令，而是通过启发式对话，揭示资产配置的集中度风险，辅助用户建立独立的理财认知框架。
* **动态决策陪伴**：在市场极端波动（如压力测试场景）时主动介入，以通俗的语言解构波动成因，对冲非理性操作。

### 2. 合规与边界（AI 不是万能的）
* **边界恪守**：定位为“决策辅助与陪伴”，绝不越界输出确定性的投资指令。
* **底层风控**：每次输出投资相关分析，系统底层强制封装合规免责声明。
* **幻觉抑制**：依赖真实账本数据作为强约束，最大程度限制大语言模型的发散。

## 🚀 核心架构与功能

### 1. 资产集成中枢（Unified Ledger）
* **多维极速导入与智能归类**：摒弃繁琐的手工录入。我们的 **AI 视觉引擎（基于 Superun OCR）** 实现了质的飞跃：
  * **精准识别与平台映射**：自动提取金额，并通过账户截图的 UI 特征，**智能判断所属机构（如招商银行、同花顺、蚂蚁财富）**，完成自动归类。
  * **代码级资产映射**：精准识别资产类别，自动抓取基金与股票代码。
* **实时行情追踪**：基于提取的资产代码，直连真实市场 API，实现 T-1 日涨跌幅追踪与总资产动态监控。
* **视觉化平台归属**：资产明细中的「平台」列会自动为常见机构呈现品牌标识，包括招商、建设、工商、中国、农业、交通、中信、兴业、浦发、平安、汇丰、渣打等银行，以及同花顺、天天基金、支付宝 / 蚂蚁财富、微信等交易 / 支付平台；未匹配到的平台原样保留文字，不影响你已有的账户命名。
* **多币种智能核算**：内置统一汇率引擎，打破币种壁垒，呈现真实的全局净值。

### 2. 深度洞察引擎（Deep Insights）
* **核心亮点：底层资产 X 光穿透（X-Ray）**。这是 FinSight 的杀手锏。我们剥离基金名称的伪装，通过底层算法对公募基金、证券等资产进行深度拆解：
  * **击碎“假分散”**：系统将直接持有的标的与基金底层的隐形持仓合并，精准定位被多只基金同时重仓的“重复暴露（Duplicate Holdings）”个股。
  * **智能健康度预警**：自动核算真实行业分布。当触发单票权重过载（>15%）、单一行业过度集中（>40%）或现金流缓冲枯竭（<10%）时，系统即刻触发 Critical/Warning 级别的风控告警。
* **宏观压力测试（Stress Test）**：依托 X-Ray 的底层数据，模拟极端市场冲击（如股灾、汇率剧震），前置暴露组合的脆弱性。

### 3. 动态问诊模型（Dynamic Advisor）
* **自适应角色切换**：AI 会根据资产健康度动态调整沟通策略。在日常场景中，它是温和的“理财教练”；当系统捕获到**高危持仓或流动性危机（如应急准备金 < 3 个月）**时，模型瞬间切换为严厉的“理财医生”，以极其直接的指令阻断危险决策。
* **分层决策树**：针对处于资产积累期（总额较少）的用户，模型自动旁路复杂的宏观分析，直接输出可落地的行动指南。
* **流式交互**：无缝唤起，实时解答财务疑问，深度解构复杂财报。

## ⚡ 敏捷构建：Superun 生态赋能

在 MVP 阶段，**Superun AI Gateway 及其云端生态**是我们得以极速完成复杂业务闭环的基石。我们将底层繁重的工作交给了这些精准的 API 与 Agent “小兵”：

1. **零样本视觉识别与特征提取（`superun-vision-flash`）**：
   在持仓 OCR 场景中，传统方案需要为各大金融机构编写极度冗杂的模板匹配规则。我们调用视觉大模型，完美实现了从非结构化图片中提取金额、**判断 UI 平台特征**、**抓取证券代码**并输出标准化 JSON 的全流程。
2. **自适应推理大脑（`superun-think-pro`）**：
   作为问诊模型的核心引擎，它处理了高难度的逻辑推理与语气把控。结合后端代码中的风控算法，该模型能够极其自然地在“温和投顾”与“严厉医生”之间无缝切换，并支持流式（SSE）输出，带来了极具沉浸感的交互体验。
3. **无服务器基础设施**：
   通过 Superun S3 Pre-signed URL 网关解决鉴权，依托 Edge Functions 承载核心算法，让产品团队得以将全部精力倾注于用户体验与交互设计。

### 当前已落地功能（MVP）
- [x] 基于 React 18 + Tailwind 的绝美 UI 与动态仪表盘。

### 后续规划与最大挑战
- **独立化与桌面端进化**：当前强依赖 BaaS（Supabase/Superun 云端），下一步挑战是**构建自有 Node.js (Fastify) 后端**并封装为 **Electron 桌面端**，以实现更极致的本地隐私保护（安全存储 Refresh Token，脱敏数据）。
- **实时数据源接入**：当前基金/股票数据为数据库预置，后续需对接真实的外部金融数据 API。
- **跨平台受控分享**：开发独立的 `share-web`，实现带有效期的资产快照脱敏分享。
