# 财务 X 光 · 建设规划

演示里所有数字都写死在演示用户小王身上。下面这份规划，是我准备接着做的事：把每一处“看得见的功能”接到真实数据、真实账户、真实计算上，让任何一位用户注册进来，都能得到属于自己的资产透视报告。

## 账户与登录

演示里没有账户，所有人打开都是小王的数据。上线后每个用户都有自己的房间：

- **游客试用**：首次打开网页会自动注册一个匿名账户，录入的资产、看过的 X 光、和 AI 医生的对话都会存在本设备的会话里，不需要先注册就能完整体验。
- **邮箱账户**：侧栏底部和 Landing 页都有登录/注册入口。匿名会话下点

## 资产归集

演示里放的是“手动、CSV、OCR、一键载入小王”四个入口卡片。真正的资产归集是这样：

- **手动录入**：保留现在的表单形态，用户逐条添加银行存款、股票、基金、保险、现金理财等资产；提交后写入你的私人账本。
- **CSV 批量导入**：允许上传从各金融 App 导出的持仓清单，系统解析后归入账本；解析失败的行会摊在屏幕上，让用户逐条修正后再入库。
- **截图 OCR 识别**：支持一次拖入或选择多张持仓截图（最多 8 张），交给 **superun AI 的视觉理解能力**逐张读图，提取基金名称、代码、市值等字段；多张结果会自动汇总到同一张核对表，用户在预览里改错、补漏，再一次性入库。
- **持仓截图与凭证**：截图、CSV 文件、导出的报告 PDF 等大文件，统一放进 **Storage（超算对象存储）**；账本里只保留引用，加载列表时不用把大文件拖出来。
- **多币种支持**：每条资产都带有独立币种（人民币、美元、港币、欧元、英镑、日元、新加坡元、韩元、新台币、澳元、加元），OCR 识图时会自动读出金额前的 `$`/`HK$`/`€` 等符号并选好币种；CSV 支持额外的 `币种` 列（可写 ISO 代码、中文别名、或者直接写符号），或者直接在金额单元格里带符号；手动录入也可以选币种。数据库层强制币种必须在支持集合内，非法值不会入账。账本表金额列会用对应符号（$ / HK$ / € 等）单独渲染每一行，一眼看清哪条是外币；总资产、平台占比、类别占比、基金 X 光、压力测试、AI 医生诊断、季度分享报告的所有汇总数字都按内置参考汇率折算成人民币再合计，含任意外币资产时会明确标注"折算"。
- **改币时金额自动换表达单位，人民币等值保持不变**：在手动录入表单、CSV / OCR 识别结果核对页、以及资产账本里的“编辑资产”弹窗里，切换某行的币种时，金额会按同一套**内置参考汇率**自动换算（例如把 5000 CNY 改成美元，会变成约 704 USD）。因为总资产、平台占比、基金 X 光等所有中文汇总数字也走同一套参考汇率，所以切换币种就只是“换一个表达单位”，**人民币等值不会因此变化**，总资产不会跳。
- **账本批量管理**：账本页顶栏支持按名称/代码搜索，按类别、平台、币种、来源筛选；表格每行都有勾选框，可以本页全选或跨页选中全部匹配项，然后一键**批量删除**、**批量改平台**（比如把误录成"招行"的一批改成"招商银行"）、**批量改类别**（比如把误分到"其他"的余额宝一键归入"现金理财"）、**批量改币种**。
- **同平台聚集展示**：账本明细列表默认按平台归类排序 —— 同一平台的资产会紧挨在一起，同平台内再按加入时间倒排，避免多平台资产被时间打散；不做文件夹式折叠，保持一张平表方便阅读和批量操作。
- 每位用户看到的账本，只有自己的；哪怕数据量大，仪表盘上的列表也会分页加载，不会一次性把全部资产吐出来。

演示用户「小王」不会消失 —— 会作为“样例账户”常驻，让第一次进来的人不用先录数据也能看到完整体验。

## 资产全景仪表盘

演示里的总资产、生命体征评分、类别分布、诊断摘要都是硬编码的。上线版本会这样跑：

- 打开仪表盘时，从账本里**只拉当前登录用户的资产**，实时汇总；
- 总资产、类别占比、平台分布直接从本人账本汇总；集中度、行业暴露、应急金告警等深度指标由 X 光穿透、压力测试两个后台计算服务专门产出；仪表盘上的"生命体征评分"目前以现金缓冲、X 光集中度、应急金月份三个已有指标在浏览器内组合展示，后续会把该公式也下沉到后台；
- 如果你在另一个页面刚改过资产，仪表盘会通过**实时同步能力（Realtime）**自动把数字刷新，不用手动点"刷新"。
- 高频查看的"近期动态"

## 基金 X 光穿透

演示里“茅台真实暴露 18%”“消费+医疗 62%”是提前写好的结论。上线版本会真的穿透：

- 目前先提前内置一批**常见基金的底层持仓**（以乐方达蓝筹、中欧医疗、招商白酒、广发科技、华夏沪深 300 等为代表）作为首批底稿，用户一键“扫描”就能得到真实的行业与个股暴露；后续会向实时公开重仓接口扩展；
- 由**计算服务**把用户的所有基金摊平、按底层股票和行业汇总，再和用户直接持有的股票叠加，算出真实的行业暴露、Top 个股集中度和重复持仓；
- 未收录的基金不会默默丢掉——报告里会单独列出“仍需手工核实底层”的基金，提醒用户知情；
- 计算结果按“账户 + 快照时间”存进数据库，下次打开报告直接读最新快照，只在用户点“重新扫描”时才重新计算；
- 扫描动效保留 —— 那时它对应的是真实计算在服务端跑的过程，不是纯装饰。

## 极端情景压力测试

演示里的四个场景（2022 熊市、2020 疫情、2015 股灾、失业+急用钱）用的是估算数字。真实版本：

- 先内置一份**常见行业在历史情景下的典型跌幅底表**（食品饮料、医疗生物、电力设备、电子科技、金融、家电、互联网等），作为压力测试的底稿；后续可替换为真实历史跌幅曲线、不改变接口；
- 用户点某个场景时，由**计算服务**把用户组合套上对应的板块跌幅，算出预计损失、回撤幅度、恢复期、应急金支撑月数；
- 同一轮的四个场景会绑定同一个"运行批次"写入，避免并发重跑的时候把不同时间的结果混在一起；
- "失业+急用钱"场景不涉及市场行情，会按用户填写的每月硬性支出 + 5 万急用金（共 6 个月开支 + 一次性支出）与现金直接计算，仅在现金不够时才计入投资资产的折价变现损失。

## AI 财务医生问诊

演示里的对白都是预置好的。上线版本会真的和 AI 对话：

- 引擎层面目前统一走**superun AI 网关（chat completion）**：每次提问前系统自动把你的当前账本、最近一次 X 光、最新一轮压力测试结论、月度硬性支出作为上下文注入模型，AI 回答时直接引用真实数据；后续会升级为多步工具调用形式，但不会改变对外行为；
- **即时逐字体验**：点常见问题或发送自己的提问后，你的消息会立即在对话栏里出现，不需等待；AI 医生的回复也会逐字产出，你能实时看到医生“写”出每一句话；
- 预防滥用：同一账户每小时 20 条、每 24 小时 100 条的问诊上限，避免匿名会话刷穿付费模型额度；
- 每一段对话都会存到账户里，下次再打开还能看到历史；
- AI 的角色定位不变：**诊断师，不当投顾**。系统层面会强制在每次回复末尾附上后台控制的风险提示，不管模型写了什么；一旦发现严重集中度或应急金告警，AI 的语气会自动切到犀利模式。

## 季度体检报告导出与分享

演示里的“导出季度体检报告”按钮只是占位。真实版本：

- 使用**网页转图片能力（HTML to Image Export）**，在分享页一键把体检报告导出为长图，方便发给家人或伴侣；
- 分享链接本身存在后台的只读快照（包含账本、X 光、压力测试三块数据），资产名称自动脱敏，不需用户手动处理；
- 分享链接可以设置有效期（例如 7 天）或随时撤销，家人/伴侣点进去只能看，不能改，也看不到账户里的其他资产明细。

## 数据边界（一句话总结）

你的资产、你的诊断报告、你和 AI 的对话，都是你自己的：只有登录进来的本人能看；仪表盘和列表一次只拉当前用户的数据，且按页加载；分享出去的报告是一份“快照”，随时可以撤回。

## 整体如何拼在一起

```
+----------------------------------------------------+
|                    用户网页应用                    |
|  登录 · 录入资产 · 看仪表盘 · X 光 · 压力测试 · 问诊 |
+---------------------+------------------------------+
                      |  登录 / 上传 / 查询 / 对话
                      v
+----------------------------------------------------+
|                    超算后台服务                    |
|  - 账户系统：认账、隔离、分享链接                  |
|  - 数据账本：每人一份的资产、报告、对话历史        |
|  - 计算服务：X 光穿透 / 压力测试 / 生命体征评分    |
|  - 实时同步：账本一改，仪表盘立刻跟着变            |
|  - 对象存储：截图、CSV、导出的报告图              |
+----+----------------+--------------------+---------+
     |                |                    |
     v                v                    v
+---------+   +--------------+     +-----------------+
| 外部基金 |   | AI 诊断医生   |     |  网页转图片能力  |
| 持仓 API |   | 智能体 + 网关 |     |  用于导出报告   |
+---------+   +--------------+     +-----------------+
```

- **用户网页应用**：小王们看到、点到的一切界面；除了本地交互，所有真正的数据和计算都问“超算后台服务”要。
- **超算后台服务**：整个产品的中枢 —— 谁能看什么、每份报告归谁、真实数字怎么算、账本变了怎么广播出去、大文件放哪，都在这里。
- **外部基金持仓 API**：只有做基金穿透时才会向外发请求，拿到的原始数据先落到超算后台再算，前端不直连。
- **AI 诊断医生**：统一走 AI 网关，后台在提问前自动拼好包含当前账本、X 光、压力测试的上下文一并发送。
- **网页转图片能力**：只在导出报告时用一下，把界面拼成一张可以发给家人的图，存进对象存储再给出分享链接。
