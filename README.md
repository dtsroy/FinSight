# FinSight 📊

> **你的下一代个人财富洞察中枢**
>
> *Every Great Product Starts with Context. 真正的理财投顾，从理解你的每一笔资产开始。*

FinSight 是一款以浏览器为中心的桌面级财富管理网页应用（React 18 + Vite），由 Superun 云端账本 + 本地行情桥接后端协同支撑。它把机构级的金融分析模型（底层穿透、压力测试）与前沿大语言模型深度融合，旨在成为**普通人的首个智能理财教练与决策陪伴中枢**。未来会演进到 Electron 本地端，进一步收敛隐私边界。

我们的设计哲学代号为 **Pawn（兵）**。
在金融的棋局中，散户往往是最容易被牺牲的 Pawn。但通过无数个精准执行的 API 与 Agent “小兵”的协同，我们将原本只属于高净值人群的机构级视野，赋能给每一个普通的 Pawn。当无数个 Pawn 获得全盘的 Context，便能化被动为主动，直击棋局的核心。

## 🎯 赛道切入点：Context 与真实痛点

### 1. 目标人群
**具备一定资产积累，但缺乏体系化认知的理财新手与新中产。**
他们广泛使用各类理财工具，但资产极度分散（银行、第三方平台、券商等），无法形成全局视角的资产管理。

### 2. 真实存在的痛点（Why this problem?）
* **“糊涂账”现象**：各大平台的资产犹如孤岛。用户每天重复打开多个 App 汇总资产，却依然无法看清真实的跨市场配置比例。
* **黑盒化投资**：持有多只基金，却不知底层重仓了相同的股票。一遇行业动荡，全盘皆崩。
* **情绪化交易**：市场波动时极度焦虑，缺乏客观、冷静的决策陪伴。
* **Why Us？**：我们自己就是痛点的亲历者。每天手动整合资产的折腾，构成了我们最宝贵的 Context。我们不是在空想一个软件，而是在解决切肤之痛。

## 🤖 产品哲学：重塑投顾交互

我们坚信：**真正的智能，不是把传统问卷包装成聊天框，而是改变交互范式，将专业的“投顾服务”平民化。**

### 1. 决策生成引擎
* **全景 Context 注入**：摒弃静态问卷。基于用户的全局资产账本（含穿透后的底层持仓）作为核心 Context，确保建议的精准度。
* **认知框架重塑**：不提供直接的买卖指令，而是通过启发式对话，揭示资产配置的集中度风险，辅助用户建立独立的理财认知框架。
* **动态决策陪伴**：在市场极端波动（如压力测试场景）时主动介入，以通俗的语言解构波动成因，对冲非理性操作。

### 2. 合规与边界（AI 不是万能的）
* **边界恪守**：定位为“决策辅助与陪伴”，绝不越界输出确定性的投资指令。
* **底层风控**：每次输出投资相关分析，系统底层强制封装合规免责声明。
* **幻觉抑制**：依赖真实账本数据作为强约束，最大程度限制大语言模型的发散。

## 🚀 核心架构与功能

### 1. 资产集成中枢（Unified Ledger）
* **多维极速导入与智能归类**：摒弃繁琐的手工录入。我们的 **AI 视觉引擎（`superun-vision-flash`）** 实现了质的飞跃：
  * **精准识别与平台映射**：自动提取金额，并通过账户截图的 UI 特征，**智能判断所属机构（如招商银行、同花顺、蚂蚁财富）**，完成自动归类。
  * **代码级资产映射**：精准识别资产类别，自动抓取基金与股票代码。
  * **拖拽 + 批量**：文件入口默认给"多文件 + 拖拽"，一次可以处理整批账单截图。
* **实时行情追踪**：基于账本里提取的资产代码，双引擎直连真实市场数据 —— **Panda AI Quant** 提供 A 股日 K 涨跌、证券名称与行业分类，**同花顺开放接口**提供基金日涨跌与最新披露的前 10 大重仓。资产明细里的当日涨跌与总资产变化随之动态刷新。
* **视觉化平台归属**：资产明细中的「平台」列会自动为常见机构呈现品牌标识，包括招商、建设、工商、中国、农业、交通、中信、兴业、浦发、平安、汇丰、渣打等银行，以及同花顺、天天基金、支付宝 / 蚂蚁财富、微信等交易 / 支付平台；未匹配到的平台原样保留文字，不影响你已有的账户命名。
* **多币种智能核算**：内置统一参考汇率引擎，11 种常见币种一键折算成人民币等值口径，改币 / 批量改币 / 总资产 / X 光 / 压测 / 分享报告全部共用同一套汇率，打破币种壁垒。

### 2. 深度洞察引擎（Deep Insights）
* **核心亮点：底层资产 X 光穿透（X-Ray）**。这是 FinSight 的杀手锏。系统以你账本中的每一只基金为输入，**实时向同花顺拉取该基金披露的前 10 大重仓**，按你实际持仓金额加权摊到底层个股，再叠加直接持股，得到穿透后的真实敞口。X 光页面以 2×2 布局呈现四块内容，把「谁最重」「哪个行业最重」「表面分散是不是真的」「未披露空洞」四个问题一次答齐：
  * **Top 10 穿透后个股（列表）**：把所有基金摊平后合并直接持股得到的真实个股榜单；若存在披露不足或未收录的基金仓位，会在头部醒目提示未穿透金额，避免"假分散"错觉。
  * **Top 5 行业分布（列表 + 完整柱状图）**：对穿透后的个股逐只调用 Panda AI Quant 拿真实行业分类后聚合；下方紧跟一张横向柱状图，把 Top 5 行业、其他行业合计、未识别行业金额、未穿透基金仓位拼成 100% 全资产画像，覆盖不到的部分明确标出"未识别"，绝不做行业推断幻觉。
  * **跨基金重仓预警（列表）**：精准定位被 2 只以上基金同时重仓的"重复暴露（Duplicate Holdings）"个股，只挑合计占比 ≥1% 的最明显几只，把"表面上分散、实际集中"的问题打成一句话。
  * **穿透后个股相对占比（环形饼图）**：把 Top 8 个股按占比由深到浅铺开、其余合并成"其他 N 只"、未穿透基金仓位单列灰色，从颜色深浅一眼看清"哪里是真分散、哪里是假分散"。
* **智能健康度预警**：聚焦穿透后的真实个股暴露与现金缓冲。单票权重过载（>15%）或现金流缓冲枯竭（<10%）会触发 Critical / Warning 级风控告警；同一只股票被多只基金重仓时则以提示级（Info）提醒"假分散"；存在未穿透基金仓位时以警告级提醒潜在盲区。
* **宏观压力测试（Stress Test）**：依托 X-Ray 的底层数据，按资产大类（股票 / 基金 / 债券 / 保险 / 现金理财 / 存款）模拟 2015 股灾、2020 疫情冲击、2022 熊市与家庭失业等历史级冲击，前置暴露组合的脆弱性。

### 3. 动态问诊模型（Dynamic Advisor）
* **自适应角色切换**：AI 会根据资产健康度动态调整沟通策略。在日常场景中，它是温和的"理财教练"；当系统捕获到**高危持仓或流动性危机（如应急准备金 < 3 个月）**时，模型瞬间切换为严厉的"理财医生"，以极其直接的指令阻断危险决策。
* **分层决策树**：针对处于资产积累期（总额较少）的用户，模型自动旁路复杂的宏观分析，直接输出可落地的行动指南。
* **流式交互**：无缝唤起，实时解答财务疑问，深度解构复杂财报。

### 4. 季度体检报告与受控分享
* 一键把当次 X 光穿透 + 关键健康度告警打包成脱敏快照，生成带 30 天有效期的公开链接，方便与家人 / 理财顾问共享讨论，链接失效后自动不可访问。

### 5. Landing 页——产品主页，也是一张可导出的海报
首页 `/` 同时承担两个角色：对新用户是产品介绍，对团队则是可直接截图分享的宣传海报。自上而下共五层：
1. **Hero 主标语**（“你以为的分散，可能只是棋局的表象”）+ 两个 CTA（免费开始 / 看 X 光报告）；
2. **双雷达面板并排**：左右两张会自动扫描 / 鼠标翻转的 3D 雷达卡，直接复用登录后 X 光页面的真实可视化组件——左卡是“穿透后个股相对占比”环形图（Top 8 + 其他 + 未穿透基金仓位），右卡是“完整行业分布”横向柱状图（Top 5 + 其他行业 + 未识别 + 未穿透），hover 就能看到真实情境下的 tooltip；
3. **六件武器 3×2 能力卡**：从视觉导入、平台名牌、双引擎行情到 X 光穿透、压力测试、AI 医生，一眼看完能力地图；
4. **我们使用的技术**：三张居中并排的白底品牌卡（Superun、Qoder、Panda AI），重新确认“每一段路交给最擅长的服务”；
5. **支持 OCR 识别的银行与机构无限横向滑动**（从左向右）：一排统一白底外框的机构品牌卡持续轮播，鰠鳞目告知“你家银行能不能用”，hover 可暂停细看。

## ⚡ 敏捷构建：Superun 生态 + 自建行情桥接

在 MVP 阶段，**Superun AI Gateway 及其云端生态**是我们得以极速完成复杂业务闭环的基石。我们将底层繁重的工作交给了这些精准的 API 与 Agent "小兵"：

1. **零样本视觉识别与特征提取（`superun-vision-flash`）**：
   在持仓 OCR 场景中，传统方案需要为各大金融机构编写极度冗杂的模板匹配规则。我们调用视觉大模型，完美实现了从非结构化图片中提取金额、**判断 UI 平台特征**、**抓取证券代码**并输出标准化 JSON 的全流程。
2. **自适应推理大脑（`superun-think-pro`）**：
   作为问诊模型的核心引擎，它处理了高难度的逻辑推理与语气把控。结合后端代码中的风控算法，该模型能够极其自然地在"温和投顾"与"严厉医生"之间无缝切换，并支持流式（SSE）输出，带来了极具沉浸感的交互体验。
3. **无服务器基础设施**：
   通过 Superun S3 Pre-signed URL 网关解决鉴权，依托 Edge Functions 承载 X 光穿透、压力测试、AI 问诊、分享报告等核心算法，让产品团队得以将全部精力倾注于用户体验与交互设计。
4. **金融行情桥接层（自建）**：
   金融行情不走 Superun，而是由我们自建的 **本地 Python FastAPI 后端**（`backend/`）作为桥接层：对上封装 Panda AI Quant（A 股日 K / 名称 / 行业）与同花顺（基金日涨跌 / 基金前 10 大重仓）两家真实数据源，对下通过 **cpolar 内网穿透隧道**以 HTTPS 暴露给云端前端，避免 Mixed Content 拦截与凭证泄露。

## 🛠 技术资源组合

* **前端**：React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui + Recharts（数据可视化）+ next-themes（浅色 / 深色主题）+ Framer Motion（微交互）
* **云端账本 & 边缘计算**：Supabase Postgres + Auth + Edge Functions + Realtime + S3-compatible 对象存储（通过 Superun 云端提供）
* **大模型**：
  * `superun-vision-flash`（OCR 截图提取 + 平台特征识别）
  * `superun-think-pro`（投顾推理 + 教练 / 医生人格切换）
  * 提示词工程：动态组装用户资产快照 + 风险声明 + 角色设定
* **金融数据源（自建行情桥接层）**：
  * **Panda AI Quant** — A 股日 K 涨跌、股票名称、行业（板块）分类
  * **同花顺（fund.10jqka.com.cn）** — 基金日涨跌、基金最新披露的前 10 大重仓
  * 承载：Python 3 + FastAPI + Uvicorn；对云端前端通过 cpolar HTTPS 隧道暴露
* **开发工具链**：Superun 平台（需求到上线的一体化构建与部署）+ Qoder（仓库级知识库与代码理解，输出到 `.qoder/repowiki`，支撑多人接手与架构回顾）
