The root is a flat Vite monorepo entry — there are no sibling packages; all source lives under `src/` and the children summaries describe logical folders within it. Cross-child wiring happens through three shared contracts defined here:
- Path alias `@/* → ./src/*` in `tsconfig.json` plus the matching Vite `resolve.alias` so every feature folder (`features/`, `components/`, `lib/`, `hooks/`) imports via absolute `@/...` paths.
- shadcn/ui registry in `components.json` declares the canonical locations for generated primitives (`@/components/ui`), utilities (`@/lib/utils`), hooks (`@/hooks`), and the base CSS file (`src/index.css`), which every UI-heavy child consumes uniformly.
- Shared runtime dependencies declared at the root (`@supabase/supabase-js`, `react-query`, `zod`, `sonner`, `framer-motion`, `recharts`, `three`+`@react-three/fiber`) form the cross-feature contract: data access goes through Supabase, validation through Zod schemas, notifications through Sonner, charts through Recharts, and any 3D/stress-test visualisation through Three.js — no child should re-declare these locally.
Build-time splitting is centralized in `vite.config.ts` (`manualChunks: vendor | ui`) and heavy deps (`lucide-react`, `framer-motion`, `recharts`) are pre-bundled via `optimizeDeps.include`. The only dev/build surface is `pnpm dev | build | preview` from this directory.
