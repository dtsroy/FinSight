- All imports use the `@/` path alias instead of relative paths (enforced by both tsconfig and vite resolve.alias).
- UI primitives come exclusively from `@/components/ui` generated by shadcn/cli; application-specific wrappers live under `@/components`.
- Form validation uses zod schemas paired with react-hook-form via `@hookform/resolvers`; schemas belong in `@/lib` and are reused across features.
- Side effects and API calls go through `@tanstack/react-query` rather than direct fetch calls, keeping data fetching consistent across feature folders.
