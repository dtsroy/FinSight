### Identity
Supabase project `bv0atyuqnuwjoaxr70wz` provides auth, edge functions, and storage for FinSight.

### Role in this repo
- Frontend client is initialized via `@supabase/supabase-js` with `VITE_SUPABASE_URL` / `VITE_SUPABASE_PUBLISHABLE_KEY` env vars; session persisted to `localStorage` with auto-refresh.
- All business logic runs as Supabase Edge Functions under `supabase/functions/` (OCR, CSV parse, X-Ray report, stress test, AI chat, shared report, S3 pre-sign URL). Most require JWT verification (`verify_jwt = true`) except `read-shared-report`.
- Database schema lives in `supabase/migrations/`.

### Integration shape
- Auth: email/password or OAuth through the JS client; secrets injected via Vite env — never hard-coded.
- Edge Functions: called from `src/services/*` (e.g. `chatService`, `xrayService`, `importService`).
- Storage: S3-compatible pre-signed URLs generated by the `s3-pre-sign-url` function.
